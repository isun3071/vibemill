AI INFERENCE PATTERN:

You need to actually wire up AI inference for the bot's responses.
Use ONE of these no-key, no-signup paths — pick whichever you prefer:

(A) **Puter.js** — simplest. One script tag and one method call:
```tsx
// In page.tsx, "use client":
useEffect(() => {
  const script = document.createElement("script");
  script.src = "https://js.puter.com/v2/";
  script.onload = () => setReady(true);
  document.body.appendChild(script);
}, []);

// Send a message:
const reply = await (window as any).puter.ai.chat(userMessage);
```

(B) **LLM7.io** — OpenAI-compatible, no token, just fetch:
```tsx
const res = await fetch("https://api.llm7.io/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    model: "gpt-3.5-turbo",
    messages: [
      { role: "system", content: "You are a..." },
      ...history,
      { role: "user", content: userMessage },
    ],
  }),
});
const data = await res.json();
const reply = data.choices?.[0]?.message?.content;
```

Both go down occasionally, rate-limit you, or return weird outputs.
That is on-brand for the genre — flaky AI responses are exactly what
real hackathon chatbots do. Catch errors and show a generic "Sorry,
something went wrong. Try again." message. Do NOT build elaborate
retry logic or fallback chains.
